# 生态

TomlSmith 分为五个仓库。Rust 库、CLI、语言服务器与 Playground 共用解析和格式化实现，另外两个仓库分别存放基准测试与视觉资源。

## 仓库

| 仓库 | 是什么 |
| --- | --- |
| [tomlsmith](https://github.com/tomlsmith/tomlsmith) | 核心：Rust 库（`tomlsmith`）、CLI（`tomlsmith-cli`）与语言服务器（`tomlsmith-lsp`） |
| [playground](https://github.com/tomlsmith/playground) | 使用 WebAssembly 检查和格式化 TOML 的浏览器工作台 |
| [vscode-plugin](https://github.com/tomlsmith/vscode-plugin) | `tomlsmith-lsp` 的 VS Code 扩展客户端 |
| [benchmark](https://github.com/tomlsmith/benchmark) | 对比 TOML 检查器与格式化器的端到端 CLI 测量 |
| [icon-assets](https://github.com/tomlsmith/icon-assets) | 项目图标与社交预览图的源文件和导出文件 |

## Playground

[Playground 源码仓库](https://github.com/tomlsmith/playground)会构建纯浏览器工作台：

- 在 TOML 1.0 与 TOML 1.1 之间显式切换。
- 分析结果与格式化预览随编辑自动刷新；只有你主动应用，才会写回源文件。
- 按源码位置跳转诊断，悬停或使用键盘聚焦时可以查看信息。
- 并排查看格式化后的文档、诊断、token 与文档统计。
- 界面可选择英文或简体中文。

分析与格式化在当前浏览器标签页本地运行，不上传源码。
