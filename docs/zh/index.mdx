  <h2 className="ts-section__title">TomlSmith 能做什么</h2>
  <p className="ts-section__note">选择 TOML 1.0 或 1.1，然后运行 <code>check</code>、<code>fmt</code> 或 <code>parse</code>。</p>
  <div className="ts-grid">
    <article className="ts-card">
      <span className="ts-card__index">01 · 版本</span>
      <h3 className="ts-card__title">明确选择版本</h3>
      <p className="ts-card__body">每次调用选择 TOML 1.0 或 1.1。Cargo 或其他只支持 1.0 的工具要读取文件时，使用 <code>--toml-version 1.0</code>。</p>
    </article>
    <article className="ts-card">
      <span className="ts-card__index">02 · 检查</span>
      <h3 className="ts-card__title">检查文档</h3>
      <p className="ts-card__body"><code>check</code> 报告错误与警告，并包含源码区间和诊断码。</p>
    </article>
    <article className="ts-card">
      <span className="ts-card__index">03 · 格式化</span>
      <h3 className="ts-card__title">带保护的格式化</h3>
      <p className="ts-card__body">已覆盖的场景会保留注释和字面量写法。有解析或语义错误的文档不会被改写；<code>fmt --check</code> 只检查，不修改文件。</p>
    </article>
    <article className="ts-card">
      <span className="ts-card__index">04 · 自动化</span>
      <h3 className="ts-card__title">读取 JSON 输出</h3>
      <p className="ts-card__body"><code>parse</code> 输出 JSON，包含所选版本、文档是否有效以及诊断，供脚本和工具读取。</p>
    </article>
    <article className="ts-card">
      <span className="ts-card__index">05 · Rust</span>
      <h3 className="ts-card__title">使用 Rust API</h3>
      <p className="ts-card__body">用 <code>Document</code> 解析一次，再查询诊断、格式化结果、高亮和解码后的值。</p>
    </article>
    <article className="ts-card">
      <span className="ts-card__index">06 · 编辑器</span>
      <h3 className="ts-card__title">使用编辑器或浏览器</h3>
      <p className="ts-card__body">连接支持 LSP 的编辑器，使用 VS Code 客户端或浏览器 Playground。</p>
