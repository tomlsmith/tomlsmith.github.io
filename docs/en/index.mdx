    </article>
    <article className="ts-card">
      <span className="ts-card__index">03 · Formatting</span>
      <h3 className="ts-card__title">Formatting with safeguards</h3>
      <p className="ts-card__body">Formatting preserves comments and literal spellings in covered cases. Documents with parse or semantic errors are not rewritten, and <code>fmt --check</code> checks files without changing them.</p>
    </article>
    <article className="ts-card">
      <span className="ts-card__index">04 · Automation</span>
      <h3 className="ts-card__title">Read JSON output</h3>
      <p className="ts-card__body"><code>parse</code> emits the selected version, validity, and diagnostics as JSON for scripts and tools.</p>
    </article>
    <article className="ts-card">
      <span className="ts-card__index">05 · Rust</span>
      <h3 className="ts-card__title">Use the Rust API</h3>
      <p className="ts-card__body">Parse once with <code>Document</code>, then query diagnostics, formatted output, highlights, and decoded values.</p>
    </article>
    <article className="ts-card">
      <span className="ts-card__index">06 · Editors</span>
