# Ecosystem

TomlSmith is split across five repositories. The Rust library, CLI, language server, and playground share the parsing and formatting implementation; the remaining repositories contain benchmarks and visual assets.

## Repositories

| Repository | What it is |
| --- | --- |
| [tomlsmith](https://github.com/tomlsmith/tomlsmith) | The core: Rust library (`tomlsmith`), CLI (`tomlsmith-cli`), and language server (`tomlsmith-lsp`) |
| [playground](https://github.com/tomlsmith/playground) | Browser workbench for checking and formatting TOML with WebAssembly |
| [vscode-plugin](https://github.com/tomlsmith/vscode-plugin) | The VS Code extension client for `tomlsmith-lsp` |
| [benchmark](https://github.com/tomlsmith/benchmark) | End-to-end CLI measurements across TOML checkers and formatters |
| [icon-assets](https://github.com/tomlsmith/icon-assets) | Source files and exports for project icons and social previews |

## The playground

The [playground source repository](https://github.com/tomlsmith/playground) builds a browser-only workbench:

- Switch explicitly between TOML 1.0 and TOML 1.1.
- Analysis and a format preview refresh automatically as you edit; the preview never touches your source until you choose to apply it.
- Navigate diagnostics by source position and read messages on hover or keyboard focus.
- Inspect the formatted document, diagnostics, tokens, and document statistics side by side.
- Choose an English or Simplified Chinese interface.

Analysis and formatting run locally in the current tab. Source is not uploaded.
